🛒 Trivio - Full Stack E-Commerce Website

Trivio is a full-stack e-commerce web application built using React.js, Node.js, Express.js, MongoDB, Firebase Authentication, and Razorpay. The platform allows users to browse products, view product details, add items to the cart, securely authenticate using Firebase, and complete purchases through Razorpay payment integration.

✨ Features
User Registration and Login using Firebase Authentication
Product Listing with Search Functionality
Product Details Page
Shopping Cart Management
Secure Checkout Process
Razorpay Payment Gateway Integration
Order Placement and Order History
MongoDB Database Integration
Responsive UI built with React and Tailwind CSS
🛠️ Tech Stack
Frontend: React.js, React Router, Axios, Tailwind CSS
Backend: Node.js, Express.js
Database: MongoDB Atlas, Mongoose
Authentication: Firebase Authentication
Payment Gateway: Razorpay
🎯 Project Objective

The objective of this project is to demonstrate the development of a complete e-commerce platform with modern web technologies, including user authentication, database management, payment processing, and full-stack integration.

This project showcases practical implementation of CRUD operations, REST APIs, authentication, payment gateway integration, and responsive frontend development.
